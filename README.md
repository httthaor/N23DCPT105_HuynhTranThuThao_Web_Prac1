# Bài Thực Hành 1: Xây dựng Blog Listing Page với Next.js & Tailwind CSS

- **Họ và tên:** Huỳnh Trần Thu Thảo
- **Mã sinh viên:** N23DCPT105
- **Mô tả ngắn:** 
  - Khởi tạo dự án Next.js sử dụng App Router và cấu hình Tailwind CSS.
  - Xây dựng component tái sử dụng: Header, Badge, BlogCard.
  - Lấy dữ liệu 12 bài viết từ REST API JSONPlaceholder và hiển thị dưới dạng Responsive Grid.
  - Hoàn thiện Dynamic Route `/blog/[id]` để xem chi tiết bài viết với nút quay về trang danh sách.
